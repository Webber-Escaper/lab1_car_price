# Лабораторная работа №1. Car Price Prediction

## Описание проекта

Цель проекта — подготовить структуру проекта и провести разведочный анализ данных (EDA)
для задачи прогнозирования цены подержанного автомобиля.

Используется датасет **Car Price Prediction**.  
Целевая переменная: `Selling_Price`.  
Тип задачи: **регрессия**.

Исходная выборка содержит **301 объектов и 9 столбцов**.
После удаления полных дубликатов осталось **299 объектов**.

## Запуск

Для Ubuntu 22.04:

```bash

cd <ИМЯ_РЕПОЗИТОРИЯ>

python3 -m venv .venv_lab1
```

и открыть `eda/eda.ipynb`.

## Исследование данных

В ходе EDA были выполнены следующие действия:

- проверены размер выборки, типы данных и основные статистики;
- проверены пропущенные значения — пропусков не обнаружено;
- обнаружены и удалены **2 полных дубликата**;
- проверены значения цены, года, пробега и количества владельцев на базовую валидность;
- статистические выбросы не удалялись автоматически, поскольку экстремальные значения
  могут соответствовать реальным дорогим автомобилям или автомобилям с большим пробегом;
- создан новый признак `Car_Age` — относительный возраст автомобиля:
  `max(Year) - Year`.

### Основные закономерности

1. Распределение `Selling_Price` имеет правую асимметрию:
   медиана около **3.51**, а среднее около **4.59**.
2. Между `Present_Price` и `Selling_Price` наблюдается сильная положительная связь
   (корреляция примерно **0.88**).
3. Автомобили с дизельным двигателем в этой выборке в среднем/по медиане продаются дороже бензиновых,
   однако это наблюдение относится именно к составу данного датасета.
4. Для автомобилей с автоматической коробкой медианная цена выше, чем для автомобилей
   с механической коробкой.
5. У продавцов типа `Dealer` медианная цена выше, чем у `Individual`.
   Это не означает причинную зависимость: группы отличаются по составу автомобилей.
6. `Car_Age` имеет отрицательную связь с ценой: более старые автомобили в среднем дешевле,
   хотя зависимость не является строгой для каждого автомобиля.
