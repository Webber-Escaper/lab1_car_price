# Лабораторная работа №1. Car Price Prediction

## Описание проекта

Цель работы — подготовить структуру проекта и провести разведочный анализ данных (EDA)
для задачи прогнозирования цены подержанного автомобиля.

Используется датасет **Car Price Prediction — Used Cars**:  
https://www.kaggle.com/datasets/vijayaadithyanvg/car-price-predictionused-cars/data

Тип задачи — **регрессия**.  
Целевая переменная — `Selling_Price`.

Исходная выборка содержит **301 объект и 9 столбцов**.
После удаления двух полных дубликатов осталось **299 объектов**.

## Запуск

Рекомендуемое окружение для лабораторной работы — **Ubuntu 22.04, Python 3.10**.

Клонировать репозиторий:

```bash
git clone https://github.com/Webber-Escaper/lab1_car_price.git
cd lab1_car_price
```

Создать и активировать виртуальное окружение:

```bash
python3 -m venv .venv_lab1
source .venv_lab1/bin/activate
```

Установить зависимости:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Скачать датасет по ссылке выше и сохранить исходный CSV как:

```text
data/car_data.csv
```

После этого открыть `eda/eda.ipynb` в Jupyter Notebook или VS Code и выполнить ячейки последовательно сверху вниз.

## Разведочный анализ данных

В ходе EDA были выполнены следующие действия:

- изучены размер выборки, типы признаков и основные статистики;
- выделены числовые, дискретные и категориальные признаки;
- определена целевая переменная `Selling_Price`;
- проверены пропущенные значения — пропусков не обнаружено;
- обнаружены и удалены **2 полных дубликата**;
- выполнены базовые проверки валидности цены, пробега и количества владельцев;
- категориальные признаки приведены к типу `category`;
- статистические выбросы не удалялись автоматически без предметного основания;
- создан новый признак `Car_Age` — относительный возраст автомобиля внутри выборки.

### Основные результаты

1. Распределение `Selling_Price` имеет правую асимметрию:
   среднее значение выше медианы из-за небольшого числа дорогих автомобилей.
2. Между `Present_Price` и `Selling_Price` наблюдается сильная положительная связь
   с корреляцией около **0.88**.
3. В данной выборке дизельные автомобили имеют более высокую типичную цену продажи,
   чем бензиновые; категория `CNG` слишком малочисленна для устойчивых выводов.
4. Медианная цена автомобилей с автоматической коробкой выше, чем у автомобилей
   с механической коробкой.
5. В группе `Dealer` медианная цена выше, чем в группе `Individual`,
   однако это не интерпретируется как причинная зависимость.
6. `Car_Age` связан с ценой отрицательно: более старые автомобили в среднем дешевле.

## Графики

В директории `eda/` сохранены **6 статических графиков** и **1 интерактивный график Bokeh**:

- `graph1_selling_price_distribution.png` — распределение целевой переменной;
- `graph2_present_vs_selling.png` — связь текущей цены и цены продажи;
- `graph3_fuel_type_boxplot.png` — цена по типу топлива;
- `graph4_transmission_boxplot.png` — цена по типу коробки передач;
- `graph5_seller_type_median.png` — медианная цена по типу продавца;
- `graph6_correlation_matrix.png` — матрица корреляций;
- `graph7_interactive.html` — интерактивный scatter plot.

Подробный анализ и вывод после каждого графика находятся в `eda/eda.ipynb`.
