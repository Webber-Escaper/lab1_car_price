# Краткая подготовка к защите ЛР1

## Что было сделано
Работа посвящена разведочному анализу датасета Car Price Prediction.
Задача — регрессия, целевая переменная — `Selling_Price`.

Исходно: 301 строк, 9 столбцов.
Пропусков нет. Найдено и удалено 2 полных дубликата.
После очистки: 299 строк.
Создан признак `Car_Age = max(Year) - Year`.

## Главные результаты
- `Present_Price` имеет сильную положительную связь с `Selling_Price`
  (корреляция ≈ 0.88).
- Цена имеет правостороннее распределение:
  среднее ≈ 4.59, медиана ≈ 3.51.
- В данном датасете дизельные автомобили обычно дороже бензиновых.
- Автоматическая коробка в этой выборке связана с более высокой типичной ценой.
- У `Dealer` медианная цена выше, чем у `Individual`.
- `Car_Age` связан с ценой отрицательно.

## Контрольные вопросы

### Что такое requirements.txt?
`requirements.txt` содержит основные библиотеки и их версии,
необходимые для воспроизведения программного окружения проекта.

### Что такое виртуальное окружение?
Это изолированное Python-окружение для конкретного проекта.
Оно позволяет не смешивать версии библиотек разных проектов.

### Как создать и активировать окружение?
```bash
python3 -m venv .venv_lab1
source .venv_lab1/bin/activate
pip install -r requirements.txt
```

### Зачем нужен EDA?
Чтобы до обучения модели понять структуру и качество данных,
найти пропуски, дубликаты и аномалии, изучить распределения,
связи признаков с целевой переменной и определить дальнейшую обработку.

### Какие графики использованы?
Гистограмма — распределение одного числового признака.
Scatter plot — связь двух числовых признаков.
Boxplot — сравнение распределений между категориями и поиск выбросов.
Bar chart — сравнение агрегированного показателя между категориями.
Heatmap — визуализация корреляций.
Bokeh — интерактивное исследование отдельных объектов.

### Почему не удалили все выбросы?
Статистический выброс не обязательно является ошибкой.
Например, дорогой автомобиль или автомобиль с большим пробегом может быть реальным.
Без предметного основания такие строки удалять нельзя.
